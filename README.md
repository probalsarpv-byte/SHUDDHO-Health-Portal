# SHUDDHO Health Portal

Interactive Health Tools & Biomedical Learning Platform

## About
SHUDDHO Health Portal is a mobile-first, interactive
health education platform featuring scientific learning
modules, health calculators, nutrition tools, and
evidence-based health information.

## Main Features
- Health Calculators and Risk Assessment Tools
- Interactive 3D Human Anatomy
- Metabolism and Biochemistry Explorer
- Physiology Simulations
- Bangladesh Food Composition Database
- Nutrition Analysis and Meal Tracking
- Scientific Health Articles
- Bengali and English Language Support
- Dark and Light Modes
- Progressive Web App (PWA)

## Technology
- GitHub for source code
- Cloudflare for hosting
- Mobile-first responsive design
- JavaScript-based interactive learning
- Future Android APK support

## Development Status
Initial development phase.
